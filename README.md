# Juan Oliveira Meireles

1- Diminui o acumulo de lixo e ajuda quem precisa de alguns moveis para a casa

2- A primeira tela eu mostro a tela de início do aplicativo, Mostrando alguns moveis que estariam e a condição deles (Isso é mostrado para todos os produtos)
A segunda Tela  eu mostro a Aba de Produtos e a opção de procurar por certo item que deseja, ainda podendo filtrar o que não quer ver
A terceira tela é só a base da aba de conversa, mostraria o nome e a foto da pessoa que você está falando
A quarta tela é mostrando o menu de um produto com uma pequena descrição e a opção de falar com o dono do item
A quinta tela é mostrando o Perfil e os Selo Ecos que seriam uma pontuação para quanto mais doações e retiradas você fez.

3- Ele começa na tela inicial, Vai para a tela de produtos e pesquisa, procura o produto que quer, clica nele, fala com o dono do produto, marca um horário para retirada e é só ir e pegar!
